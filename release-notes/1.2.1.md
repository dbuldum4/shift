# Shift 1.2.1

This security maintenance release replaces Node.js 22.23.1 in the web-extraction
pack with Node.js 22.23.4, including the October Brotli, TLS and CA-trust fixes.
Packaging rejects unpatched runtimes, the managed Defuddle launcher checks its
interpreter, and release validation extracts and tests the shipped Node binary
and a local HTML conversion.

Install this app update and reinstall the web-extraction pack through setup.
Existing 1.2.0 apps remain pinned to their old component URL and checksum.
Conversion formats, source-file preservation and optional setup remain unchanged.

Shift downloads remote pages with curl and gives Defuddle local HTML; a Node
network exploit through that existing application path has not been demonstrated.
Development installs using an external Defuddle CLI should update its actual
Node interpreter too.

The macOS builds retain the existing ad-hoc signing and are not Apple-notarized.
