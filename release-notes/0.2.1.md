# Shift 0.2.1

Patch release focused on Defuddle reliability for macOS GUI installs.

## Changes

- Resolve Node for bundled Defuddle when the app launches with a minimal GUI
  `PATH` (Homebrew, nvm, fnm, volta, asdf, and mise layouts)
- Fail with a clear “Node.js not found” message instead of `exec: : not found`
- Inject discovered `SHIFT_NODE_BIN` when spawning Defuddle from the app/CLI
- Surface Node install hints in diagnostics and conversion failures when Node is
  the missing piece (not only `npm install -g defuddle`)
- Document `SHIFT_NODE_BIN` in Settings → Paths

## Runtime

Same system requirements as 0.1.x. The Homebrew cask installs the native tools
required by the bundled runtime: Python 3.11, Node, FFmpeg, Pandoc, Typst, and
qpdf. Packaged Shift already embeds Defuddle; a working Node binary is still
required to run it. Docling may download model weights on first use.

## macOS security notice

This preview is ad-hoc signed because the project does not yet have an Apple
Developer ID certificate. It is not notarized. macOS may require Control-click →
Open on first launch. A future release will replace this with Developer ID
signing and notarization.
