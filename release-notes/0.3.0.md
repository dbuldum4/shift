# Shift 0.3.0

Shift 0.3.0 adds in-process spreadsheet conversion for tabular formats across
the native app and CLI.

## Changes

- Add a spreadsheet adapter (calamine + csv + rust_xlsxwriter) for
  xlsx/xlsm/xlsb/xls/ods/csv/tsv → csv/tsv/xlsx as cell values only
- Expose sheet name and 1-based sheet index controls in the app and CLI
- Keep document → Markdown/HTML routes with MarkItDown, Docling, and Pandoc;
  sheet-native paths default-suggest CSV and remain chainable into document
  engines
- Persist spreadsheet options in session settings and surface the module in
  diagnostics, preferences, history, and registry parity coverage

## Runtime

Spreadsheet conversion is fully in-process and requires no extra install.
Other converter requirements are unchanged: the Homebrew cask installs Python
3.11, Node, FFmpeg, Pandoc, Typst, and qpdf. Packaged Shift embeds Defuddle;
Docling may download model weights on first use. The sips image engine is
built into macOS.

## macOS security notice

This preview is ad-hoc signed because the project does not yet have an Apple
Developer ID certificate. It is not notarized. macOS may require Control-click →
Open on first launch. A future release will replace this with Developer ID
signing and notarization.
