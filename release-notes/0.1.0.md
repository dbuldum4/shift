# Shift 0.1.0

The first public preview of Shift: a native, opinionated file converter for
macOS with matching app and CLI surfaces.

## Included

- Native `Shift.app` and bundled `shift-cli`
- MarkItDown, Docling, and Defuddle application packages
- Document, web, PDF, audio, video, frame, subtitle, and batch conversion routes
- Shared conversion behavior and diagnostics across the app and CLI

## Runtime

The Homebrew cask installs the native tools required by the bundled runtime:
Python 3.11, Node, FFmpeg, Pandoc, Typst, and qpdf. Docling may download model
weights on first use.

## macOS security notice

This preview is ad-hoc signed because the project does not yet have an Apple
Developer ID certificate. It is not notarized. macOS may require Control-click →
Open on first launch. A future release will replace this with Developer ID
signing and notarization.
