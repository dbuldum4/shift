# Shift 1.1.0

Shift 1.1.0 follows the 1.0.0 stable release with a broad security and
reliability hardening pass, plus small native UI polish.

## Highlights since 1.0.0

- **Security and reliability hardening** — strengthen public URL and redirect
  validation, credential redaction, temporary-file permissions, process
  cancellation and timeouts, artifact-cache integrity, history and settings
  durability, batch expansion, and output safety.
- **Release pipeline hardening** — validate release metadata and checksums,
  pin CI and packaging tool versions, build both Apple Silicon and Intel
  artifacts, and keep Finder document associations aligned with the converter
  catalog.
- **Diagnostics copy fix** — copy only the primary install command when a hint
  includes alternatives, while keeping the complete guidance visible.
- **Settings polish** — add restrained directional transitions between settings
  sections and restore scrolling for long settings panels.

## Runtime

The runtime requirements are unchanged from 1.0.0. Shift supports macOS 13 or
later on Apple Silicon and Intel. Packaged releases embed MarkItDown, Docling
(including ASR and video-format extras), and Defuddle. Python 3.11, Node,
FFmpeg, Pandoc, Typst, and qpdf remain explicit system requirements, and
Docling may download model weights on first use. Run `shift-cli doctor` to
inspect readiness on a particular Mac.

## Security status

This release is not yet Developer ID signed or notarized. macOS may require
Control-click → Open on first launch. Signing and notarization remain explicit
follow-up work and are not implied by this release.
