# Shift 0.2.0

Shift 0.2.0 adds native still-image conversion on macOS and expands the shared
app and CLI conversion controls.

## Changes

- Add a macOS-native sips adapter for HEIC/HEIF, AVIF, SVG, JPEG XL, camera RAW,
  PNG, JPG, TIFF, GIF, BMP, JPEG 2000, ICNS, and image-to-PDF conversions
- Add matching app and CLI controls for image size, quality, rotation, flipping,
  and color-profile removal
- Keep sips ahead of FFmpeg for still-image conversions while preserving
  FFmpeg ownership of video frame extraction and PNG sequence ZIPs
- Improve conversion capability discovery and chained-format routing
- Expand diagnostics, preferences, session persistence, history, and parity
  coverage for the new image workflow
- Harden batch conversion, artifact caching, source handling, and UI behavior

## Runtime

The sips image engine is built into macOS and requires no separate installation.
Other converter requirements are unchanged: the Homebrew cask installs Python
3.11, Node, FFmpeg, Pandoc, Typst, and qpdf. Packaged Shift embeds Defuddle;
Docling may download model weights on first use.

## macOS security notice

This preview is ad-hoc signed because the project does not yet have an Apple
Developer ID certificate. It is not notarized. macOS may require Control-click →
Open on first launch. A future release will replace this with Developer ID
signing and notarization.
