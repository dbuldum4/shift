# Shift 1.2.0

Shift 1.2.0 tightens first-run setup and keeps converter installation honest
when managed release packages are not available.

## Highlights since 1.1.1

- **Copy-paste converter setup** — onboarding shows a safe Homebrew command
  (`brew install ffmpeg pandoc typst qpdf node`) with one-click copy instead of
  a one-click installer that only works when release dependency archives are
  published.
- **Clearer install feedback in Settings** — managed dependency install reports
  live phase progress with a determinate bar when packages are available.
- **Welcome polish** — onboarding bullet markers align with their labels.

## Runtime

Shift supports macOS 13 or later on Apple Silicon and Intel. The application
bundle contains Shift and `shift-cli`. Converter CLIs are installed with
Homebrew (or your preferred package manager); MarkItDown and Docling remain
Python-based and can be added separately. When a release publishes verified
managed dependency archives, Settings can still install those private packages.
Run `shift-cli doctor` to inspect readiness on a particular Mac.

## Security status

This release is not yet Developer ID signed or notarized. macOS may require
Control-click → Open on first launch. Signing and notarization remain explicit
follow-up work and are not implied by this release.
