# Shift 0.1.1

Patch release for the 0.1 preview.

## Changes

- Keep result-card action chips (Download / Copy / Reveal / Open / Show cmd)
  inside the output panel by stacking them on a full-width wrapping row
- License the project under MIT

## Runtime

Same as 0.1.0. The Homebrew cask installs the native tools required by the
bundled runtime: Python 3.11, Node, FFmpeg, Pandoc, Typst, and qpdf. Docling may
download model weights on first use.

## macOS security notice

This preview is ad-hoc signed because the project does not yet have an Apple
Developer ID certificate. It is not notarized. macOS may require Control-click →
Open on first launch. A future release will replace this with Developer ID
signing and notarization.
