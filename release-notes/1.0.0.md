# Shift 1.0.0

Shift 1.0.0 is the first stable release of the native macOS file converter and
its parity-focused `shift-cli` companion. App and CLI share one conversion
registry, explicit capabilities, diagnostics, progress, cancellation, batch
processing, and source-preserving output behavior.

## Highlights since 0.3.0

- **qpdf PDF toolkit** — PDF → PDF and PDF → `pdf-pages-zip` with page range,
  password-protected sources, rotation, compression, linearization, and split
  grouping without mutating the source.
- **Docling transcription** — local ASR for audio and video into a dedicated
  `transcript` output (Markdown), plus expanded document formats; FFmpeg keeps
  subtitle-track SRT/VTT and MarkItDown keeps document Markdown routes.
- **Fit-to-size goals** — shared `target_size_bytes` for final artifacts; FFmpeg
  owns lossy audio/video fitting and sips owns lossy still quality ladders.
- **Batch folder workflows** — hierarchy-aware expansion, naming templates,
  per-item format selection, and multi-output fan-out through the shared batch
  queue.
- **Conversion recipes** — save and reuse option snapshots from the app and CLI
  (`shift-cli recipes`), including batch and watch paths.
- **macOS workflow integrations** — Finder Open With (alternate viewer) and
  `shift-cli watch` for folder automation outside the watched tree.
- **Binary artifact inspection** — bounded previews of media and other binary
  conversion results in the result card.
- **Spreadsheet conversion** (from 0.3.0) — in-process xlsx/xlsm/xlsb/xls/ods/csv/tsv
  routes as cell values only.

## Installation

Shift requires macOS 13 or later on Apple Silicon and Intel. Download the
architecture-matched ZIP or DMG from GitHub Releases, verify the published
SHA-256 checksum, and drag `Shift.app` to Applications. The bundled CLI lives
at `/Applications/Shift.app/Contents/Resources/bin/shift-cli`. See the README
for PATH setup, upgrade, and uninstall steps.

## Runtime

Packaged releases embed MarkItDown, Docling (with ASR and video format extras),
and Defuddle. Python 3.11, Node, FFmpeg, Pandoc, Typst, and qpdf remain
explicit system requirements. Docling may download model weights on first use.
The sips image engine is built into macOS. Use `shift-cli doctor` to inspect
what is ready on a particular Mac.

## Security status

This release is not yet Developer ID signed or notarized. macOS may require
Control-click → Open on first launch. Signing and notarization are intentionally
deferred to a later release; no claim of Gatekeeper approval is made here.
