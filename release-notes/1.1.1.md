# Shift 1.1.1

Shift 1.1.1 corrects the macOS release pipeline after the 1.1.0 tag could not
produce a complete multi-architecture release.

## Highlights since 1.1.0

- **Current GitHub-hosted images** — build and test on macOS 26, using the
  dedicated `macos-26-intel` image for x86_64 artifacts.
- **Honest Intel capabilities** — retain Docling's layout-aware document
  conversion on Intel while removing its unavailable audio/video transcript
  route from the app and CLI capability lists.
- **Architecture-aware runtime packaging** — publish verified managed
  dependency archives, including Docling ASR/video extras on Apple Silicon and
  the compatible base Docling runtime on Intel.

## Runtime

Shift supports macOS 13 or later on Apple Silicon and Intel. The application
bundle contains only Shift and `shift-cli`; onboarding can download verified,
release-pinned MarkItDown, Docling, and Defuddle components into private
Application Support storage. The Apple Silicon dependency archive includes
Docling's ASR/video extras; the Intel archive retains Docling document
conversion but omits transcription because the pinned PyTorch dependency has
no macOS Intel wheel. FFmpeg, Pandoc, Typst, and qpdf remain explicit system
requirements. Development and standalone builds also need Python 3.11 and
Node.js. Run `shift-cli doctor` to inspect readiness on a particular Mac.

## Security status

This release is not yet Developer ID signed or notarized. macOS may require
Control-click → Open on first launch. Signing and notarization remain explicit
follow-up work and are not implied by this release.
